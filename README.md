# QuantForge POC ⚡

> Algorithmic trading research, backtesting, analytics, and paper-trading proof of concept.

QuantForge is being revived as a focused POC rather than trying to complete the original full-scale trading SaaS in one pass.

## POC workflow

```
Strategy → Historical Data → Backtest → Performance Analytics → Paper Trading → Portfolio
```

## Current POC scope

- FastAPI backend foundation
- EMA Crossover strategy
- RSI Mean Reversion strategy
- Backtesting-ready strategy interfaces
- Basic health/API endpoints
- Next.js frontend foundation
- Dark trading-dashboard design system
- Recharts-ready analytics layer

## Planned POC features

- Strategy configuration
- Historical market-data ingestion
- Backtest execution
- Total return, win rate, P&L and max drawdown
- Equity curve
- Trade history
- Paper orders
- Portfolio and position tracking

## Future expansion

- VWAP Intraday
- ATR Breakout
- AI Sentiment
- Real-time market data
- WebSockets
- Broker integrations
- Automated strategy execution
- Advanced risk management
- Live trading

## Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, Recharts, Zustand
- **Backend:** Python, FastAPI
- **Analytics:** Pandas, NumPy
- **Infrastructure:** PostgreSQL, Redis, Docker

## Disclaimer

QuantForge is an educational software and algorithmic-trading research project. The POC is intended for testing and paper trading and is not financial advice.
